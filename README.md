# EMBLEM - Insurance Predictive Modeling Platform

A web-based recreation of the EMBLEM GLM (Generalized Linear Model) predictive modeling tool used in the insurance industry.

## Features

- **Terms in Model** — Select/deselect 32 candidate independent variables
- **Quick Model Comparison** — Compare current vs. reference models (Deviance, AICc, BIC, Chi-Squared)
- **Volume Summary** — View observations and weight distributions per variable level
- **Interactive Graphs** — Predicted Values, Linear Predictor, Rescaled views with confidence intervals
- **Beta Parameters** — Full parameter table with standard errors, alias indicators, and Exp(Value)
- **Beta Exporter** — Export factors to Excel/CSV format
- **Correlation Tests** — Cramer's V matrix with network graph visualization
- **Interaction Testing** — Multi-way graphs with Chi-Square significance tests
- **Curve Fitting** — Polynomial fits for continuous variables
- **Stepwise Regression** — Forward and backward variable selection
- **Model Settings** — Error distributions (Poisson, Gamma, Normal, Binomial, Tweedie) and link functions
- **Scoring Model** — Convert fitted model for deployment
